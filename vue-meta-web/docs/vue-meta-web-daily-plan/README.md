# Vue Meta Web Daily Plan

这个目录把两个月迁移计划拆成 40 个独立工作日文件。

使用方式：

- 每天只打开当天文件执行。
- 每天结束时按文件里的验收清单自测。
- 每 5 天做一次小验收，避免问题拖到最后。
- 当前计划假设你熟悉原 React 项目和业务，只需要补 Vue 迁移差异。
